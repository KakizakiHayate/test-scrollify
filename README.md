# Scrollify テストプロジェクト セットアップ手順

## 概要

このプロジェクトは、JSのScrollifyライブラリをテストするためのプロジェクトです。
PC・スマホ実機の両方で動作確認できる環境を構築します。

## セットアップ手順

### 1. HTMLファイルの作成

`index.html` を作成し、シンプルなサンプルページを実装します。

- PC/SPで表示を切り替えるメディアクエリを設定
- 768px以下をSP、769px以上をPCとして判定
- 背景色とテキストで視覚的に判別可能

### 2. ローカルサーバーの起動

```bash
npx serve
```

このコマンドで、インストール不要でローカルサーバーを起動できます。

### 3. アクセス方法

#### PCから確認

```
http://localhost:3000
```

PCのブラウザでアクセスします。

#### スマホ実機から確認

```
http://[ネットワークIP]:3000
```

例: `http://172.20.10.3:3000`

**前提条件:**
- PCとスマホが同じWi-Fiネットワークに接続されていること

**ネットワークIPの確認方法:**

```bash
ifconfig | grep "inet " | grep -v 127.0.0.1
```

または、`npx serve` 起動時に表示される "Network" の行を確認します。

### 4. 表示の確認

- **PC表示**: 青い背景 + "Device Check (PC)"
- **SP表示**: 赤い背景 + "Device Check (SPtest)"

## 次のステップ

Scrollifyライブラリを導入してテストを実施します。

## 備考

- シンプルな実装のため、後でScrollifyのコードに差し替えやすい構成になっています
- サーバーを停止する場合は `Ctrl + C` で終了できます
